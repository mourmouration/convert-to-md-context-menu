# Convert to MD — конвертация файлов в Markdown из контекстного меню Windows

Добавляет в контекстное меню проводника Windows два пункта:

- **«Конвертировать в MD»** — прямая конвертация файла в Markdown (без OCR).
- **«Конвертировать в MD (с OCR)»** — только для `.pdf`: сначала распознаёт текст (OCR), затем конвертирует результат в Markdown.

Идея и общий подход — аналог [strigov/anydoc-md-converter](https://github.com/strigov/anydoc-md-converter) (macOS), реализованный для Windows через реестр текущего пользователя, без прав администратора.

## Что поддерживается

**«Конвертировать в MD»** (без OCR) — напрямую через `markitdown`:
`.pdf`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.html`, `.htm`, `.csv`, `.txt`, `.epub`.

`.doc` (Word 97–2003) не поддерживается `markitdown` — при выборе такого файла появится соответствующее сообщение; пересохраните файл как `.docx`.

**«Конвертировать в MD (с OCR)»** — только `.pdf`. Полезно для сканов и PDF без текстового слоя.

## Требования

- Windows с PowerShell 5.1 (стандартно есть в системе).
- Python 3, доступный в PATH как `python` или `python3`.
- Пакет [`markitdown`](https://github.com/microsoft/markitdown):
  ```
  python -m pip install markitdown
  ```
  Для полной поддержки всех форматов (в т.ч. `.xlsx`/`.xls`):
  ```
  python -m pip install --upgrade "markitdown[all]"
  ```
- Для пункта с OCR — [`ocrmypdf`](https://github.com/ocrmypdf/OCRmyPDF):
  ```
  python -m pip install ocrmypdf
  ```
  `ocrmypdf` также требует Tesseract OCR и Ghostscript — см. [инструкцию по установке OCRmyPDF для Windows](https://ocrmypdf.readthedocs.io/en/latest/installation.html).

## Установка

1. Скачайте все файлы этого репозитория в одну папку на компьютере (например, `C:\Tools\ConvertToMD`). Все четыре скрипта (`ConvertToMD.ps1`, `ConvertToMD-OCR.ps1`, `Install-ContextMenu.ps1`, `Uninstall-ContextMenu.ps1`) должны лежать вместе, в одной папке.
2. Кликните правой кнопкой по `Install-ContextMenu.ps1` → **«Выполнить с помощью PowerShell»**.
   - Если Windows заблокирует выполнение скрипта политикой выполнения — откройте PowerShell в этой папке и выполните:
     ```
     powershell -ExecutionPolicy Bypass -File .\Install-ContextMenu.ps1
     ```
3. Если пункты меню не появились сразу — перезапустите проводник (`Stop-Process -Name explorer -Force`) или перезайдите в систему.

Установка производится в `HKEY_CURRENT_USER` — права администратора не нужны, другие учётные записи на компьютере не затрагиваются.

**Важно:** не перемещайте `ConvertToMD.ps1` / `ConvertToMD-OCR.ps1` в другое место после установки — команды меню ссылаются на исходный путь к файлам. Если папку нужно перенести — сначала запустите `Uninstall-ContextMenu.ps1`, перенесите папку, затем запустите `Install-ContextMenu.ps1` заново.

## Использование

Выделите один или несколько файлов в проводнике, кликните правой кнопкой → выберите нужный пункт. Поддержан мультивыбор — при выборе нескольких файлов команда выполнится для каждого отдельно.

Результаты появляются рядом с исходным файлом, в подпапке `0.1. MD`:

- **«Конвертировать в MD»**: `0.1. MD\<имя>.md`.
- **«Конвертировать в MD (с OCR)»**:
  - `<имя>_ocr.pdf` — файл с распознанным текстовым слоем, остаётся в исходной папке;
  - `0.1. MD\<имя>.md` — итоговый Markdown;
  - `0.2. Not ocr\<имя>.pdf` — исходный PDF без OCR-слоя, перенесён сюда (в исходной папке остаётся только `*_ocr.pdf`).

Если файл уже был сконвертирован ранее (результат уже есть в `0.1. MD`) — скрипт молча пропускает его. На успехе окна не показываются (это специально, чтобы не заваливать экран при конвертации сразу нескольких файлов). Окно появляется только при ошибке или при неподдерживаемом формате.

## Удаление

Кликните правой кнопкой по `Uninstall-ContextMenu.ps1` → **«Выполнить с помощью PowerShell»**. Оба пункта меню будут убраны из реестра.
