# Convert to MD — конвертация файлов в Markdown из контекстного меню Windows

Добавляет в контекстное меню проводника Windows два пункта:

- **«Конвертировать в MD»** — прямая конвертация документа в Markdown (без OCR).
- **«Конвертировать в MD (с OCR)»** — только для `.pdf`: сначала распознаёт текст (OCR), затем конвертирует результат в Markdown.

Идея — аналог [strigov/anydoc-md-converter](https://github.com/strigov/anydoc-md-converter) (macOS), реализованный для Windows через реестр текущего пользователя, без прав администратора и на других движках (OCRmyPDF + MarkItDown).

## Что поддерживается

**«Конвертировать в MD»** (без OCR), напрямую через `markitdown`:
`.pdf`, `.docx`, `.xlsx`, `.xls`, `.pptx`, `.html`, `.htm`, `.csv`, `.txt`, `.epub`.

Форматы Office 97–2003 (`.doc`, `.ppt`) не поддерживаются: в `markitdown` для них нет конвертера. Пункт меню для таких файлов всё же показывается, но выводит сообщение с советом пересохранить документ в `.docx` / `.pptx`.

**«Конвертировать в MD (с OCR)»** — только `.pdf`. Нужен для сканов и PDF без текстового слоя.

## Требования

- Windows с PowerShell 5.1 (входит в систему).
- Python 3, доступный в PATH как `python` или `python3`.
- [`markitdown`](https://github.com/microsoft/markitdown) с компонентами для нужных форматов. **Базовой установки недостаточно**: поддержка PDF, Word, Excel и PowerPoint вынесена в дополнительные наборы зависимостей, и без них конвертация этих форматов завершится ошибкой.
  ```
  python -m pip install --upgrade "markitdown[pdf,docx,pptx,xlsx,xls]"
  ```
  Либо всё сразу (включая ненужные здесь компоненты для аудио и облачных сервисов):
  ```
  python -m pip install --upgrade "markitdown[all]"
  ```
- Для пункта с OCR — [`ocrmypdf`](https://github.com/ocrmypdf/OCRmyPDF):
  ```
  python -m pip install --upgrade ocrmypdf
  ```
  `ocrmypdf` дополнительно требует Tesseract OCR (с языковыми пакетами `rus` и `eng`) и Ghostscript — см. [инструкцию по установке OCRmyPDF](https://ocrmypdf.readthedocs.io/en/latest/installation.html).

Установщик сам проверяет, что всё это на месте, и выводит недостающее с готовыми командами установки.

## Установка

1. Скачайте все файлы репозитория в одну папку на компьютере (например, `C:\Tools\ConvertToMD`). Скрипты `ConvertToMD.ps1`, `ConvertToMD-OCR.ps1`, `ConvertToMD.Common.ps1`, `Install-ContextMenu.ps1` и `Uninstall-ContextMenu.ps1` должны лежать вместе.
2. Правой кнопкой по `Install-ContextMenu.ps1` → **«Выполнить с помощью PowerShell»**.
   - Если выполнение блокирует политика запуска скриптов, откройте PowerShell в этой папке:
     ```
     powershell -ExecutionPolicy Bypass -File .\Install-ContextMenu.ps1
     ```
3. Если пункты меню не появились сразу — перезапустите проводник (`Stop-Process -Name explorer -Force`) или перезайдите в систему.

Установка выполняется в `HKEY_CURRENT_USER`: права администратора не нужны, другие учётные записи не затрагиваются.

**Важно:** после установки папку со скриптами перемещать нельзя — команды меню ссылаются на конкретные пути. Если нужно перенести: запустите `Uninstall-ContextMenu.ps1`, перенесите папку, запустите `Install-ContextMenu.ps1` заново.

## Использование

Выделите один или несколько файлов, правая кнопка → нужный пункт. При выделении нескольких файлов команда выполняется отдельно для каждого. Учтите, что для этого способа регистрации Windows ограничивает выделение примерно сотней файлов — для больших объёмов используйте папочный скрипт (`pdf_to_md_md_and_not_ocr`, отдельный репозиторий).

Результаты появляются рядом с исходным файлом:

- **«Конвертировать в MD»** — `0.1. MD\<имя>.md`. Исходный файл не перемещается и не изменяется.
- **«Конвертировать в MD (с OCR)»**:
  - `<имя>_ocr.pdf` — PDF с распознанным текстовым слоем, остаётся в исходной папке;
  - `0.1. MD\<имя>.md` — итоговый Markdown;
  - `0.2. Not ocr\<имя>.pdf` — исходный PDF без OCR-слоя, перенесён сюда.

  Перенос исходника выполняется **только** после того, как оба результата действительно получены и непусты. При любой ошибке исходник остаётся на месте, чтобы можно было разобраться и повторить.

На успехе окна не показываются — иначе при обработке нескольких файлов экран заваливало бы сообщениями. Окно появляется только при ошибке, при неподдерживаемом формате или если из документа не удалось извлечь ни одного символа.

## Повторный запуск

- Если `.md` уже есть и исходник с тех пор не менялся — скрипт молча выходит.
- Если исходник изменился — `.md` пересоздаётся. Свои правки, внесённые в `.md` вручную уже после изменения документа, при этом сохраняются: сравнивается время изменения файлов.
- Для пункта с OCR каждый шаг проверяется отдельно: OCR выполняется, если `_ocr.pdf` отсутствует или старше исходника; конвертация в Markdown — если `.md` отсутствует или старше `_ocr.pdf`. Поэтому если раньше по этому же скану обычной конвертацией был получен пустой `.md`, после OCR он автоматически пересоздаётся уже с текстом.

## Совпадающие имена

Если в одной папке лежат `Договор.pdf` и `Договор.docx`, оба документа претендовали бы на один и тот же `Договор.md`. В таком случае к имени добавляется расширение исходника: `Договор.pdf.md` и `Договор.docx.md`. Если совпадения нет, имя остаётся обычным — `Договор.md`.

## Обработка ошибок

Скрипты проверяют код завершения внешних программ и показывают расшифрованную причину сбоя вместе с сообщением самой программы — например, «PDF зашифрован или защищён паролем» или «не установлен Tesseract или Ghostscript». Результат сначала пишется во временный файл рядом и переименовывается в итоговый только после проверки, поэтому прерванная операция не оставляет обрубок, который в следующий раз сочли бы готовым результатом.

## Удаление

Правой кнопкой по `Uninstall-ContextMenu.ps1` → **«Выполнить с помощью PowerShell»**. Из реестра удаляются оба пункта. Документы и результаты конвертации не затрагиваются.
